## Version and tag decision

- **The candidate version is `0.1.0-rc.2`.** Do not bump the package version or
  rebuild for the remaining manual check. The package version and
  `package-lock.json` already agree.
- **`rc-0.1.0-rc.2` is an evidence tag, not the release tag.** It points at
  `d74fc3d`, which predates the #281–#284 fixes. It is useful as a base for
  comparison only. Do not publish from it.
- **The fixed runtime was proven on macOS from `70f3da7`.** The only source
  changes after that build are the repository-only doctor CLI and the live
  harness, which are not part of the package (`files: ["dist"]`); the runtime
  closure is unchanged.
- **The public release is still gated.** The final version and `v<version>` tag
  are cut on the approved release commit after the remaining manual check and
  publish approval. If the artifact stays at `0.1.0-rc.2`, the tag is
  `v0.1.0-rc.2` and the dist-tag is `next`. The workflow's `prepack` rebuilds
  `dist` from that commit; if any runtime source changes, rerun the
  clean-install proof before publishing and do not reuse stale evidence.
- **`0.1.0` is not cut.** A final version is a separate decision after this
  candidate has run. The prerelease publishes under the `next` dist-tag and
  never becomes `latest`.

## What is proven

  `opencode plugin add` into an isolated OpenCode 2.2.7 / Node 26.12.1 host on
  Linux, using a loopback registry: 124 runtime files, 507,824 bytes.
- `opencode plugin list` reports `ensemble.v2 0.1.0-rc.2` from the package; the
  installed server loads six native Ensemble tools; the TUI route and
  `/ensemble` command load from the installed package, not a workspace link.
- The final-tip deterministic fake E2E passes on OpenCode 2.2.7: `fake` 407 s,
  `fake-empty` 9 s, 2 passed, 0 failed/skipped/retries, flake budget ok.
- The fixed runtime (#281–#284) was rebuilt and installed on macOS through the
  same path, loads the TUI in Herdr/Ghostty, and passes the deterministic fake
  E2E and size matrix (#277). A public-registry install smoke of the final
  tagged build is still pending.
- The manual macOS checklist passes items 1.1–1.6 and 1.8–1.10, and sections
  2–9 as recorded, including Cmd+C/Cmd+V, init lifecycle, palette, motion, Work
  cards, toast, reduced motion, `NO_COLOR`, and v7 dispatch groups.
- The #281–#284 fixes were re-verified on the installed macOS candidate without
  screenshots or pointer input.
- The enforced 4-hour soak at `b194b95` passes on OpenCode 2.3.0: 240 samples,
  14,439 s, 5,240 messages, 0 failures, queue/native settled, 94.89 MiB/h and
  19.14 MiB/1k messages, no findings. The 2.2.7 rerun is still pending.
- `npm run verify` passes with 2,117 tests on Node 26.12.1; `npm run
  docs:check` passes. The CI matrices cover Node 22.23.4/24.22.1/26.12.1 and
  OpenCode 2.2.6/2.2.7.
