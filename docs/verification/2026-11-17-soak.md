This record covers two enforced 4-hour fake-provider soaks at `b194b95`:
OpenCode 2.2.7 and OpenCode 2.3.0. Both are supported hosts after #286, which
merged the 2.3.0 range and compatibility context at `a0c39c0`. The 2.3.0 run
predates the formal support merge but tested the same host behavior; #286 makes
it a supported-host result and adds the harness compatibility needed for the
Compatibility CI matrix.

## Command

```sh
ENSEMBLE_SOAK_OUT=<soak-out> npm run soak
```

`npm run soak` is the default 14,400-second enforced run. No duration override
or observe-only flag was used for either host. `<soak-out>` is the local output
directory for `soak.jsonl` and `soak-summary.json`; the path is deliberately not
recorded.

## Interpretation

- Both hosts passed both growth gates. The 2.2.7 run was 92.59 MiB/h and
  18.71 MiB per 1,000 durable messages; the 2.3.0 run was 94.89 MiB/h and
  19.14 MiB per 1,000 durable messages.
- Both runs ended with a settled durable queue and settled native state, with
  no send, sample, or TUI failures.
- Neither report printed a finding.
- Both hosts are now in the supported set (`2.2.6 || 2.2.7 || 2.3.0`) after
  #286. The 4-hour gate is therefore covered on the previous primary host and
  the current primary host.
