This record covers the enforced 4-hour fake-provider soak at the final
integration tip. The first run resolved OpenCode 2.3.0, which is outside the
supported `2.2.6 || 2.2.7` range, so this is a runtime/gate result, **not** a
supported-version claim. The 2.2.7 rerun is still in progress.

## Command

```sh
ENSEMBLE_SOAK_OUT=<soak-out> npm run soak
```

`npm run soak` is the default 14,400-second enforced run. No duration override
or observe-only flag was used. `<soak-out>` is the local output directory for
`soak.jsonl` and `soak-summary.json`; the path is deliberately not recorded.

## Interpretation

- Both growth gates passed: the absolute slope is 94.89 MiB/h against a
  256 MiB/h ceiling, and the normalized slope is 19.14 MiB per 1,000 durable
  messages against a 64 MiB ceiling.
- The durable queue and native state were settled at the tail; there were no
  send, sample, or TUI failures.
- The report printed no findings.
- The host resolved OpenCode 2.3.0. The supported-version 2.2.7 rerun has not
  finished, so this record does not prove a supported-host 4-hour soak.
