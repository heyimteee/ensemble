# Ticket #72 — bubble rendering stabilization

Scope: fix the transcript remount storm and bubble chrome regressions from the v5.5 bubble overhaul.

## Root cause and fix

- `mergedRows()` allocated fresh wrapper objects on every 250 ms snapshot poll, defeating `stableLines` and remounting native `<markdown>` rows ~4×/s — the observed ghosting/overlap. Fixed with a pure `stabilizeMergedRows` fold that reuses the previous wrapper when the inner message reference and completion payload are unchanged. Idle polls now mount nothing.
- Agent and user bubbles now use a full rounded border (`borderStyle="rounded"`) with `padding={1}` on all sides; the user edge uses the muted theme color so it is visible but quiet. Auto height accounts for padding/border.
- Fallback text and native Markdown share one wrap width (`bubbleContentWidth(..., BUBBLE_CHROME)`), so height cannot disagree when paths swap.
- The fake provider gained a long/multi-element bubble fixture for live coverage.
