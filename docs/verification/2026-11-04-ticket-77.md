# Ticket #77 — conversation surfaces: truthful colors, ordering, readable settings, safe keybinds

## Root causes and fixes

1. **Sent lines stayed grey.** `chatContext` derived `queued` as
   `queueEntryQueued || message.queued`, so the stale persisted bit on a line
   that had already been flushed outranked the queue's own truth. The queue
   entry is now the single source: a line is queued exactly while its entry is
   `queued`; sent/failed/removed entries render as sent.
2. **Names muted while bodies stayed bright.** Two independent causes:
   - `unifiedAuthorColor` returned muted for every `system`-role line before
     looking at `agentID`, so system-authored rows carrying a real agent lost
     attribution. Agent ownership now resolves first; only generic system
     rows stay muted.
   - The transcript's first-paint stagger dimmed rows with `colors.faint`.
     Native `<markdown>` bodies kept syntax colors, so only the plain-text
     header visibly dimmed, and the motion tick wrapped at 120 — letting an
     old row's mount tick recur and re-dim later. Transcript text no longer
     dims for entrance motion, and the clock is monotonic. Attribution and
     body colors are stable.
3. **Bottom jump control.** Moved from the corner (`bottom=1 right=1`, bare
   `↓`) to a rounded bordered box at `bottom=2 right=4` with panel background,
   keeping the click target and the `End` binding.
4. **Agent rail layout.** Each agent is now two lines: the name (selection
   marker + name only) and, below it, the title plus `· leader`/`guest` in the
   muted color. Workspaces keep a single row; the group counts are unchanged.
5. **Skillbox unusable.** The 40-row cap is now a real 12-row pager:
   - cursor-driven page (`j/k` crosses pages; the window always contains the
     cursor, and toggling can reach every skill),
   - `PgUp/PgDn` page jumps,
   - `page X/Y · PgUp/PgDn` indicator,
   - two-line rows (name + id) with a muted one-line description.
6. **Keybind conflicts.** Save was `Ctrl+S` (macOS maps it to `Cmd+S` via
   `platformBind`; also a system save shortcut) and backup reorder was
   `Ctrl+↑/↓`. Save is now plain `s` inside the settings layer (no global
   conflict while settings is open), reorder is `Shift+↑/↓`, and the help
   overlay and footers match.
7. **Handoff visibility/order.** Queued activity labels were only rendered
   when another agent was already live (`shown.length > 0`), so a just-handed
   task's recipient stayed invisible until someone else moved — then appeared
   late. Queued labels now render on their own, deduped against live and
   capped. Transcript merges break equal timestamps messages-first, so an
   answer can never be displaced by its own handoff completion row. The
   completion quiet window is kept only for batch consolidation (parked work
   is now visibly queued from the first poll).
