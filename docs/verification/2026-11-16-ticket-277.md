## Automation method and limits

- Ghostty AppleScript is the real input path: `send key <name> [modifiers
  "control,..."]` and `input text <text>` to the focused terminal of the
  selected tab of the front window. The disposable Herdr tab
  `ensemble-macos-test` (`w1:tD`, pane `w1:p16`) was used for every check.
- A Herdr split pane ran `screencapture -l <Ghostty window id>`, so TCC was
  inherited from Ghostty. The window id came from a small Swift
  `CGWindowListCopyWindowInfo` probe. Screenshots were window-only, inspected,
  and deleted on both hosts. One initial whole-display capture was deleted and
  is not used here; subsequent captures were restricted to the Ghostty window.
- `herdr pane read` is unreliable for OpenCode's alternate screen: it can return
  old scrollback or a stale statusline. Key results below use the visible
  screenshot, `herdr pane read --format ansi --raw`, the service snapshot, or
  the scripted fake E2E; a `pane read` miss is not treated as a product failure.
- The Herdr prefix check sent `ctrl+s` then `c` through Ghostty AppleScript and
  compared `herdr tab list` and `herdr pane list` before and after. No tab or
  pane was created; the pane shell received Ctrl+S (XOFF) and needed Ctrl+Q.
  This is recorded as a **FAIL for the prefix-ownership check**. It may be a
  Herdr context/keybinding difference or a limit of injected keys below the
  frontend key layer; it is not a pass.
- Global window-manager hotkeys and mouse-drag/selection judgement require a
  physically focused terminal and are not claimed.

## Fake E2E

From a clone of tag `rc-0.1.0-rc.2` with the two fixes on this branch:

```sh
ENSEMBLE_LIVE_REQUIRE=1 bash scripts/live-check-fake.sh   # PASS
ENSEMBLE_LIVE_REQUIRE=1 bash scripts/live-check-fake-empty.sh  # PASS
```

Both pass. The first full fake attempts failed at the doctor check with an empty
output. Root cause: `doctor-cli.ts` compared `import.meta.url` with the raw
`process.argv[1]` path; on macOS `/tmp` is a symlink to `/private/tmp`, Node
resolved the module URL to the real path, the guard was false, and the CLI
exited 0 without running `main()`. The fix compares real paths and adds a
symlink regression test (`src/v2/doctor-cli.test.ts`). This is the only product
code changed for the run.

The live harness also canonicalizes its isolated base path with `pwd -P` so
host-reported paths compare equal under the macOS `/var` symlink. The installed
package check then passed without a `TMPDIR` override.

## Follow-ups

1. **Git RC install is broken in OpenCode 2.2.7.** `opencode plugin add
   github:...#rc-...` fails during git dependency preparation with npm-style
   flags passed to `opencode`. Use the npm package or the loopback registry
   until this is diagnosed upstream.
2. **Doctor symlink entry guard fixed** on this branch; keep the regression test.
3. **Herdr prefix ownership is not proven.** `ctrl+s`+`c` through Ghostty
   AppleScript did not act as a Herdr prefix and reached the shell as XOFF.
   Re-test with a real focused terminal and Herdr's own key-event path.
4. **Braille font coverage.** The configured face has no Braille codepoints;
   the terminal fallback rendered the glyph. Add a Braille-capable font to the
   host requirements or state the fallback dependency.
5. **Size matrix on macOS** stops at `could not resolve the TUI opencode
   process`; the exact 6.3/9.7 size rows remain unmeasured by that harness.
