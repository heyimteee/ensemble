## Scope

This record covers the release identity and package contents only: the MIT
license, the scoped npm name, the publish metadata, the runtime-only contents
allowlist, and the pack-content guard. It does not change product behavior,
the OpenCode peer range, the Node floor, the exports, or the plugin IDs. No
release was published to a registry.

## Changes

### License and identity

- `LICENSE` contains the MIT text; `package.json` sets `"license": "MIT"`.
- The package name is `@heyimteee/ensemble`; `private` is removed.
- `repository`, `homepage`, `bugs`, `author`, `keywords`, and
  `publishConfig.access: "public"` are present.
- The `.`, `./tui`, and `./rpc` exports, the `@opencode/plugin` peer range
  `2.2.6 || 2.2.7`, and the `>=22.23.4` Node floor are unchanged.
- README documents the `opencode plugin add @heyimteee/ensemble` install path,
  says the package is not on the public registry yet, and links the MIT
  license. `docs/implementation.md` no longer claims the package is private.

### Runtime-only contents allowlist

`package.json` ships only `src/v2/**/*.ts` and `src/v2/**/*.tsx`, then excludes
`*.test.ts`/`*.test.tsx`, `fixtures/`, and the development-only modules
(`ci-workflows`, `doctor`, `doctor-cli`, `flake-policy`, `latency-budget`,
`live-matrix`, `prompt-benchmark`, and `test-service`). npm still adds the root
`package.json`, `README.md`, and `LICENSE`.

`src/v2/package-contents.test.ts` packs the package with
`npm pack --dry-run --json` and asserts the tarball is exactly the import
closure of the `.`, `./tui`, and `./rpc` exports. A synthetic case proves the
same check rejects a leaked test, fixture, doc, script, development module, or
`tsconfig.json`. The suite runs inside `npm run verify`.
