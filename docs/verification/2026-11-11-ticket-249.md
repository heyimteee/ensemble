## Behavior

A root synthesis turn no longer receives the bounded last-20 group transcript.
Its context carries the original request and the #246 branch digest — worker
path plus the final result for each terminal branch. Worker turns keep the
recent transcript unchanged.

The synthesis prompt asks for one concise group summary: answer the original
request, name the contributing workers, and note anything still open. It states
that `$Name` mentions are references in the terminal turn, so a name in the
summary does not start new work. The synthesis turn block uses the existing
`routing: false` mode for the same reason.

The digest reuses #246's caps: at most 20 branches, each result bounded to 600
characters plus an ellipsis. No new cap was needed.

## Measurements

`npm run benchmark:synthesis` renders a fixed five-branch fan-out over the #225
12-member roster and 20-message transcript. Token counts are the documented
chars/4 estimate; output is a fixed representative concise summary, not a live
model measurement.

| Measurement | Chars | Est. tokens |
|---|---:|---:|
| Synthesis context | 2,033 | 509 |
| Synthesis prompt text | 335 | 84 |
| Synthesis prompt total (context + text) | 2,368 | 593 |
| Removed last-20 transcript block | 1,492 | 373 |
| Representative concise summary | 303 | 76 |

For comparison, the same fixture renders a worker context at 2,904 chars
because it still carries the transcript. The pre-#245 evidence recorded 8,333
leader characters for a five-writer relay (four syntheses plus completion);
#246 removes the per-hop turns and this ticket removes the per-turn transcript,
leaving one compact prompt per command.
