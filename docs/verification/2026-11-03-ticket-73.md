## Behavior notes

- Instruction contract: `ensemble_handoff` accepts optional
  `instruction`/`constraints`/`expected` (tool args are fallbacks; file
  frontmatter wins, matching `task`/`summary`). Resolution:
  `file.instruction ?? tool.instruction ?? (summary ? task+\n\n+summary : task)`.
  Hop sets `title = task`, `instruction = brief + (path)`; the recipient
  prompt (`promptForTask`) renders it verbatim. Legacy callers without an
  instruction keep the exact old brief.
- Idempotency: `handoffWorkKey` now hashes
  `recipient + task + instruction + constraints + expected` (plus
  actor/workspace/run-prefix scope); the approval-path hop key includes
  the payload instruction too. Correlation still derives from the key.
- Group ack: all four handoff ack sites (explicit hop, single completion,
  approved cross-boundary hop, batch-review follow-up) post
  `author: "system", kind: "system"` with `Handed to $Name · <label>`
  (label = `summary || task` for explicit hops, title otherwise). The
  policy sentence + `(ref …)` stays only in the explicit tool result for
  the calling model. Duplicate/failure legs unchanged.
- Completion: single hops carry
  `$Finisher finished "title" (@path?). Review the finished turn and
  decide what happens next:\n\n<content>`; batch keeps its consolidated
  `batchReviewText` instruction. `title` stays the finished title.
- Prompts/copy: `ensemble_handoff` tool description, `identityForAgent`,
  `init-block.ts` Handoffs section (frontmatter `instruction:`, `##
  Instruction`, call signature, delegation framing), and `AGENTS.md`
  end-of-turn section all require a self-authored instruction, never a
  copy of the user's message, with `task` as the short display title and
  handoff-as-delegation (no delegate-after-handoff).
- Compatibility: waiting semantics (#70), leader-only delegate rule,
  loop guards, approvals, `$Name`/`!Name`, `@` file-only, and all live
  assertions preserved. Existing tests were updated intentionally, never
  silently weakened: relay/waiting/completion-batch/service tests now pin
  `author === "system"` + exact concise ack text + absence of policy/ref
  in the transcript, and the tool-result policy assertions stay.
