| Real-model checks stay local | The `live` job runs only the fake and empty-catalog scenarios. `test:live`/`test:live:all` are not invoked in CI. |
| Documentation | `scripts/README.md` documents tool setup, runtime, the CI flow, the skip-vs-fail contract, and local duration; the runtime guide and `CONTRIBUTING.md` link the same contract. |
