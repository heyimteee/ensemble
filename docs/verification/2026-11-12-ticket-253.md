## Contract v7

`ENSEMBLE_BLOCK_VERSION = 7`. The workspace `AGENTS.md` block keeps the v6
native-first rules and adds the terminal-turn workflow in plain language:

- one synthesis per command, written by the command root; intermediate hops
  relay their child's result and do not wake the leader;
- synthesis, completion-review, and batch-review turns are terminal, and
  `$Name` is only a reference there;
- `ensemble_dispatch` starts the next ticket as a new command root with a fresh
  group and command budget; one terminal turn starts at most one new command,
  and a retry returns the existing command and assignments;
- normal worker, handoff, and peer turns are not terminal and still route
  `$Name` to a different teammate.

The generated roster table and leader-first ordering are unchanged.

## Repository AGENTS.md

The repository block is generated, not hand-edited. A one-off script imported

verified the project-owned content was unchanged. The committed file carries

## Measurements

The generic v7 block is 5,413 chars / 1,354 estimated tokens (chars/4); the v6
block it replaces was 4,548 / 1,137. The generated identity prompt is 5,965
chars / 1,492 tokens, still under the 6,200-char compactness gate. Total prompt
size is 8,869 chars / 2,218 tokens versus the 3,347-token legacy baseline, a
33.7% reduction. The v7 contract adds 865 generic chars (~216 tokens) over v6,
so the old 40% total-prompt gate is not reachable without deleting the
terminal-turn rules; 33% is the recorded product floor with the measured 0.7pp
margin. Because that margin is too tight to be the only guard, the test also
ratchets the released v7 identity, turn-context, and total-prompt sizes
(5,965 / 2,904 / 8,869 chars) with a 2% tolerance, and a unit test proves 500
chars of contract growth fails it. The native surface remains well below the
legacy prompt and the tool-schema gate is unchanged.

The fixed 12-member filled v7 block is 6,532 chars / 1,633 estimated tokens:
the #238 v6 measurement (5,667 / 1,417) plus the 865-char v7 contract delta.
The Vera driver records the delta against that constant.
