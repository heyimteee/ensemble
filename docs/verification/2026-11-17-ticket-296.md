## Scope

This record covers the coordinated TUI runtime bump: OpenTUI 0.7.0 to 0.8.4,
Solid 1.9.12 to 1.9.19, and `babel-preset-solid` 1.9.12 to 1.9.19, plus
`@opencode/plugin` 2.3.0 for type checking. The package version stays `0.1.0`;
this is a dependency migration, not a release or a product behavior change.

## Changes

- `package.json` and a freshly generated `package-lock.json` carry the package
  set above. No `node_modules` symlink is used.
- `src/v2/package-contents.test.ts` expects the new runtime dependency versions.
- `src/v2/tui/opentui-clipboard.ts` records `0.8.4` as the verified runtime; a
  new `opentui-clipboard.test.ts` compares that claim with the installed
  `@opentui/core` package version so a future bump cannot leave it stale.
- OpenTUI 0.8 and Solid 1.9 required no TUI source changes: the existing
  `<textarea>` buffer, keymap, style, and clipboard surfaces compile and run
  unchanged.
- `@opentui/solid@0.8.4` adds `babel-plugin-module-resolver` to the installed
  runtime tree, whose `glob@9` pulled two moderate advisories into
  `npm audit --omit=dev`. A scoped override pins
  `babel-plugin-module-resolver`'s `glob` to `14.0.6`; the release gate is clean
  again and the Solid build still passes.
- Docs updated for the new checked versions: the runtime guide, host support
  range, accepted risks (`AR-271-01` resolved, `AR-271-04` counts), threat-model
  finding table, and the retired Dependabot `solid-js` ignore.
