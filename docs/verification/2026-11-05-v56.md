# Ensemble v5.6 verification — modal interactions, composer editing, mouse copy, and statusline

Spec: [#78](https://github.com/heyimteee/ensemble/issues/78). Tickets
[#79–#89](https://github.com/heyimteee/ensemble/issues) were integrated on
`integration/ensemble-v5.6`; #89 is the cleanup and full-verification pass.

Environment: Node v26.12.1, OpenCode v2.2.5 (pinned plugin types 2.2.1),
Linux/tmux, fake provider with the 60 ms chunk delay that makes the
parked-message probe deterministic. The real check used the host model catalog
and completed with one live model.

## v5.6 behavior delivered

- **#79 foundation/statusline.** One pure interaction reducer owns Normal,
  Insert, Visual (char/line), Command, focus, overlay, command input, pending
  chord, selection, and transient message. Two reserved bottom rows show the
  mode chip, context, git state, position, pending chord, hints, and the
  `:`/`/` input or latest message. The top header keeps workspace, paused, and
  busy state.
- **#80 command/search.** `:` has completion and per-kind history; `/`
  searches the transcript or filters the focused list; `Up`/`Down` recall the
  right history; `n`/`N` move matches. Commands are navigation/state only.
- **#81 Normal grammar and Leader.** Roster/chat/work share `j/k`, `gg/G`,
  `h/l`, `Tab`, `Enter`, `/`, and `Space`. Chat `j/k` scroll the transcript;
  there is no message cursor. `Space` opens the generated which-key menu and
  `?` opens help. `~` is retired.
- **#82 work list.** `Enter` opens a result; `d`, `t`, `r`, `R`, `x`, and `o`
  delegate, reassign, retry, restart, cancel, and open native sessions; `Tab`
  and `Esc` move focus.
- **#83 settings.** Tabs `h/l`, rows `j/k`, `Enter` edit/toggle, `a/e/x`,
  `Space` toggle, `p` promote memory, `J/K` reorder backups, `s` save, `/`
  filter, `Esc` close. Text fields use Insert/Normal/Visual.
- **#84 wizard/dialogs.** List steps use `j/k`, `Enter`, `Space`, `/`, `Esc`;
  text steps use the shared editor grammar and the same Esc ladder. Pickers,
  prompts, confirms, results, and approvals share the dialog grammar.
- **#85 composer Vim.** Enter sends and keeps Insert focus; `Shift+Enter`
  adds a line; Esc goes Insert → composer Normal → chat; `Ctrl+G` leaves
  immediately; `Ctrl+C` stops work. Normal and Visual implement the documented
  Vim subset with per-Workspace and per-Direct-conversation drafts.
- **#86 Visual/clipboard.** `v`/`V`, motions, `o`, `y`, `d`/`x`, `c`, `p`/`P`,
  and the Esc exit. The system clipboard is primary; deletes are cuts; the
  internal register is the fallback; async pastes discard on focus/buffer
  change; successes and failures toast.
- **#87 mouse.** The wheel scrolls the hovered pane; pane-bounded drag copies
  on release, clears on success, keeps on failure, and never changes mode or
  focus. Double-click selects a word; triple-click selects a line.
- **#88 help.** `?` opens the complete, sectioned, searchable catalog generated
  from the same binding/command/mouse tables as the keymaps and statusline; a
  coverage test proves every source appears exactly once.
- **#89 cleanup.** The retired interaction layer is gone, the Leader is
  documented as `Space`, and the full matrix below is recorded.

## #89 root causes and fixes

1. **`:` was swallowed after an F2 native round-trip.** The event shape was
   already `{ name: ":", sequence: ":" }`; normalization was not the cause.
   The host keeps the previous Ensemble page mounted when navigation pushes a
   new page, and both pages kept a raw `renderer.keyInput` listener. The stale
   listener received `:` first, opened Command mode in its hidden state, and
   called `stopPropagation`, so the visible page never saw the key. A new
   `page-activation.ts` mount stack lets only the newest mounted page handle
   raw keys and enables generated keymap layers; unmounting the top page
   reactivates the one beneath. Unit tests pin the stack, and the fake live
   harness now asserts `:` and `/` after F2.
2. **Colon normalization hardening.** `normalizeKeyToken` now maps `:`/`colon`,
   a `:` sequence, and Shift+`;` (including the shape a terminal may report
   after its keyboard protocol resets) to `:`. The raw Normal handler and
   composer Normal both use the normalized token, so `:` opens Command mode in
   every route and `/` still opens search.
3. **Composer focus race.** `focusComposer` queued a microtask while the
   Insert hint rendered immediately, so a fast key could land before the
   textarea received focus. `focus.ts` now focuses an existing ref
   synchronously, keeps one queued retry for first mount (or a focus call that
   races the mount), and is shared by the composer, settings fields, wizard
   fields, prompts, and snapshot-refresh refocus.
4. **Legacy bindings removed.** Deleted the `legacy.*` catalog entries
   (`Ctrl+W`, `Ctrl+Shift+W`, `Ctrl+A`, `Ctrl+Shift+A`, `Ctrl+Shift+Delete`)
   and their handlers, removed the dead platform keymap layer and the unused
   `platform.ts` helper/tests, and removed the stale `~` live probe. Archive,
   delete, and reset remain deliberate: roster `x`/`X`, leader `Space w` /
   `Space W` / `Space A` / `Space D`, and the confirmed `/reset-ensemble`
   composer command.
5. **Docs and tests.** `GLOSSARY.md` defines the Leader as `Space`;
   README, implementation notes, scripts README, live help checks, and
   generated help now use `Space` / `Space q` / `:q`. Stale one-Esc real-live
   assertions were updated to the v5.6 two-step composer ladder.

## Remaining limits

- **macOS/Herdr manual check was not performed.** This environment is
  Linux/tmux; there is no macOS host or Herdr session. Follow the
  [repeatable macOS/Herdr checklist](macos-herdr-checklist.md) on that host; it
  is manual and unexecuted until a run is recorded. The user should confirm
  there is no clash with host shortcuts and that `Esc`/`Ctrl+G` behave as
  documented while a native run streams.
- The host keeps old plugin pages mounted; the page-activation guard protects
  key ownership, but the host owns whether those old pages are ultimately
  disposed. Their polling continues until the host removes them.
- Real mouse drag behavior remains a manual check because tmux mouse injection
  is not reliable; the reducer/clipboard seam is unit-covered.
- Windows-specific terminal behavior was out of scope in the spec.

## Post-integration review-fix pass (same date)

Baseline: `integration/ensemble-v5.6` at `acbe168`. Branch:
`fix/v56-review`. This pass addressed the review findings without starting new
features, editing/closing issues, or merging into the integration branch.

### Findings and fixes

1. **Stale platform docs.** `docs/implementation.md` no longer claims every
   Ctrl shortcut becomes Cmd on macOS or that labels follow the platform. It
   now records that the v5.6 platform keymap layer is gone and lists the only
   Ctrl app chords: `Ctrl+C` stop, `Ctrl+D`/`Ctrl+U` half page, `Ctrl+G` leave
   editor, and `Ctrl+R` redo.
2. **Unverified macOS/Herdr claim.** `README.md` now presents
   collision-free `Ctrl+letter` intent as design intent, explicitly unverified
   on a macOS/Herdr host, instead of claiming no collision.
3. **EOF whitespace.** Removed the blank line at the end of
   `src/v2/tui/vim.test.ts`; `git diff --check` is clean.
4. **Clipboard cast.** Replaced the silent `as` cast with
   `src/v2/tui/opentui-clipboard.ts`, a typed adapter over the clipboard
   exports. Verified against the installed `@opentui/core` 0.7.0 types and
   runtime (`createHostClipboard`, `createClipboard`,
   `createRendererClipboardAdapter` are all exported). The adapter keeps a
   capability guard: an older peer build returns null and Vim falls back to
   its in-memory register.
5. **Reverse focus traversal.** Added `Shift+Tab` catalog entries for the
   roster, transcript, and work list, and the pure `nextFocusZone` helper
   (forward: rail → chat → work → chat; reverse mirrors it). The composer is
   documented as entered with `i`/Enter, not Tab, in help and the README.
6. **List half pages.** Added `Ctrl+d`/`Ctrl+u` bindings, handlers, and hints
   for the roster, work list, and settings rows, backed by the pure
   `halfPageCursor` helper.
7. **Ctrl+G in wizard/prompt fields.** Added insert/field-Normal catalog
   entries and routed them through the reducer's `leave.editor` intent.
   Wizard fields go back one step; prompt fields cancel; settings fields
   return to settings rows. Tests cover the typed intents.
8. **One quit path.** Removed `/leave`. `:q` and `Space q` both call one
   `leaveEnsemble` helper; no other quit exists.
9. **Catalog/handler drift.** `handleHelpKey`, `handleCommandKey`,
   `handleComposerKey`, and the wizard/prompt field handlers now resolve
   catalog ids through `singleKeyEntry`/`resolveNormalKey` instead of
   duplicating key lists. Added the missing composer Normal `Enter`/`Ctrl+G`
   and `:`/`/`, full wizard/prompt/settings Vim tables generated from one
   shared spec, help page keys, and leader hints. Statusline hints, the
   in-chat composer line, `footerLine1`, and the settings field line are all
   catalog-generated. Tests now assert required handler bindings independently
   of the help catalog, plus help coverage of the special-case entries.
10. **Mouse pane bound.** `normalizeRendererSelection` refuses a selection
    when the drag's start pane is unknown, instead of copying every selected
    renderable. The test that blessed the cross-pane fallback now asserts the
    selection is ignored.
11. **Transcript position.** Added `transcriptPosition` (real scroll
    percentage) and fed it from `scrollTop`/`scrollHeight`/viewport metrics;
    the bar no longer shows `100%`/`scrolled` as a boolean label.
12. **Leader which-key delay.** `Space` activates leader mode and actions
    immediately; the popup appears after `LEADER_POPUP_DELAY_MS` (250 ms).
    Pure `leaderPopupVisible` tests pin the timing and immediate key
    resolution.
13. **macOS/Herdr.** Not performed in this Linux/tmux environment. This
    record does not claim it passed; the manual check remains a user task.

Small cleanups completed: one `keyChordLabel` formatter (removed `keyLabel`),
removed unused `ParsedCommand.args`, inlined the `dialogFilterEdit` wrapper,
consolidated the duplicated `contextLabel` maps, and aliased
`InteractionSelection` to the Vim Visual range type. The 4,000-line
`app.tsx` split remains a follow-up and was not attempted.
